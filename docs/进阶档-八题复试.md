# 进阶档 · SkillRet 八题复试

## 选题和控制变量

从与主实验相同版本的 SkillRet 官方测试集中选 8 道多技能题，排除原十题。按此前整题融合的测试记录分层，选 6 道有部分命中的题和 2 道零命中的题。每层按 `SHA-256("rsi-flow-retest-v1:" + 题号)` 升序取样。历史记录只用于分层，复试报告使用平台重新跑出的 A/B。按原题中的交付物或任务意图写好各题 2–3 条查询，再统一运行。官方标注用于分层统计和运行后评测，分支查询按原题编写。

复试只增加题号和分支配置。A、B 从同一个原题开始，词法和向量索引、模型、语料、三个逻辑分片、加权 RRF、各节点候选数量和最终 Top 10 都沿用主实验。B 在同一画布保留整题检索，额外按需求补查，依旧保留整题前三，每个分支顺序追加最多两条未选候选，再由整题候选补足。8 道题均从 RSI 可视化页面触发 A/B，经 Java 流程调用同一检索服务。对照时复核了 A 的排名和 B 整题节点的排名一致，并根据官方标注和最终名次独立重算五项指标。

## 结果

| 指标 | A 整题 | B 按需补查 | 变化 |
| --- | ---: | ---: | ---: |
| Recall@10 | 41.67% | 70.83% | +29.17 个百分点 |
| Precision@10 | 10.00% | 17.50% | +7.50 个百分点 |
| Completeness@10 | 0.00% | 37.50% | +37.50 个百分点 |
| NDCG@10 | 41.28% | 54.73% | +13.45 个百分点 |
| MAP@10 | 31.25% | 40.29% | +9.04 个百分点 |

表内各项为 8 题算术均值，变化由未四舍五入的数据计算。6 道部分命中题中 3 道补齐、3 道召回持平。2 道零命中题均新增命中，仍有漏召回。合计 5/8 题召回提升，3/8 题完全修复。完全修复指从至少漏掉一项变为官方标注技能全部进入最终 Top 10。

整题检索保留完整语境和高排名候选。分需求查询缩小各节点要匹配的意图，例如把混合题里的「写提示文案」或「发布流水线」作为独立查询。以上结果表明，这套编排在同一数据集的新题上可复用，也有两类可复现的限制。第一类是节点候选前十都未覆盖标注技能，现有合并阶段没有相应候选可选。第二类是候选已出现，但固定名额会漏掉相关项或压低原先命中的名次。本次保留这些失败和排名回退，合并规则仍按冻结配置运行。

本批是先前基线漏召回样本，数据支持对这 8 道题的结论。三个分片仍为本地模拟。按相同完全修复口径，原组 2 道加复试 3 道，累计 5 道完全修复。
