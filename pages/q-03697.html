整题融合检索

Our research group is finishing a systematic review on the effectiveness of container orchestration strategies for reducing deployment failures across CI/CD pipelines. We have data extracted from 23 primary studies (2018–2024) covering variables like rollback frequency, mean time to recovery, deployment cadence, toolchain (ArgoCD, Flux, Spinnaker, etc.), and environment type (Kubernetes, Docker Swarm, ECS). I need two things done in our `~/repos/sr-container-deploy` repo: (1) Build me a comprehensive evidence synthesis matrix as a structured Markdown file at `docs/synthesis_matrix.md` that organizes all 23 studies by rows, with columns for study ID, year, sample size, orchestration tool, deployment strategy (blue-green, canary, rolling), outcome metrics, effect direction, risk of bias rating, and key findings — including a summary section at the bottom that identifies cross-study patterns, areas of convergence/divergence, and gaps in the evidence. (2) Then update our `.github/workflows/review-pipeline.yml` GitHub Actions workflow so that whenever `docs/synthesis_matrix.md` is modified on a PR, it triggers a job that runs a Python validation script (`scripts/validate_matrix.py` which checks for missing fields and duplicate study IDs), builds a Docker container from our `Dockerfile.review-tools` that generates an HTML version of the matrix with sortable columns, and uploads both the HTML artifact and a summary comment back to the PR. The current workflow only runs linting — I need the new synthesis validation and artifact generation stages added as dependent jobs.
