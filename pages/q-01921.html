We're launching a new internal developer portal called "DevNexus" for our platform engineering team — it's a Next.js 14 app with a dashboard where engineers can spin up ephemeral environments, view deployment statuses, and manage feature flags. I need three things done together: First, design and build the main dashboard page with a polished, production-grade UI — it should have a sidebar nav, a top bar with user avatar and notifications bell, a grid of environment cards showing status (running/stopped/deploying) with color-coded badges, and a feature flags toggle panel with search and filtering, all following modern design patterns with proper spacing, typography hierarchy, and dark mode support. Second, generate a full PRD for the "Ephemeral Environments" feature covering the self-service provisioning flow, TTL-based auto-teardown, cost tracking per team, and Kubernetes namespace isolation — make sure it's structured for task breakdown with acceptance criteria, tech constraints, and dependency mapping, and then hand it off to TaskMaster for execution planning. Third, set up our git workflow guardrails for this repo: conventional commit enforcement via Husky pre-commit hooks (feat/fix/chore/docs/refactor scopes), branch naming conventions following `type/PORTAL-{ticket}-short-description`, a PR template that includes sections for screenshots of UI changes, a "Breaking Changes" checkbox, and required reviewer checklist items, plus document the emergency bypass procedure for hotfixes.
