We have a screenplay repo called "EchoTide" on GitHub — it's a sci-fi feature script written in Fountain format, and we want to set up a GitHub Actions workflow that automatically parses the .fountain file on every push to `main`, counts the total pages based on standard screenplay formatting (dialogue-heavy scenes vs. action-heavy scenes with appropriate genre adjustments for sci-fi pacing), estimates the projected runtime using the one-page-per-minute baseline with corrections, and then posts a comment on the commit with a summary like "Current page count: X, Estimated runtime: Y min, Target delta: ±Z min from the 110-minute feature target." If the estimated runtime drifts more than 15 minutes over or under the target, the workflow should also open an issue labeled `length-warning` with details about which acts are running long or short. Can you write the full workflow YAML plus the Python script it calls to do the page counting and runtime estimation?
